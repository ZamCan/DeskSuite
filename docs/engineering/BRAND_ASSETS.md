# Brand asset sources and regeneration

The canonical current description is [DeskSuite brand assets](../BRAND_ASSETS.md): the owner-selected blue dimensional DS scan-frame image, generated Android/desktop resources, internal section illustrations, regeneration and outstanding device checks. Earlier warm-vector descriptions are superseded.

Fictional page/design samples are separate from the logo. `tools/generate_practice_documents.py` regenerates some sample assets with Python, Pillow, NumPy and local DejaVu fonts; the generated still-life is a separate project sample. See [starter templates and practice packs](TEMPLATE_SAMPLE_PACKS.md) and [third-party notices](../../THIRD_PARTY_NOTICES.md).
