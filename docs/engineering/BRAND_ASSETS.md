# DeskSuite brand assets

- `assets/branding/desksuite-logo.svg` is the editable master wordmark source.
- `lib/app/theme.dart` paints the in-app DS document monogram.
- Android 8.0 and later use the adaptive icon in `mipmap-anydpi-v26/ic_launcher.xml`, with a vector foreground and warm clay background.
- Existing legacy-density PNG launcher icons remain for older Android versions; a regenerated multi-density PNG set is still required before claiming the full launcher asset set is complete.

The mark uses a folded document silhouette and a connected D/S monogram in warm clay, paper white and antique-gold accents. Do not copy third-party logos. When producing marketing PNG assets, render the SVG transparently at the required resolution and inspect its small-size legibility.
