# Conversion registry and support boundaries

The in-app **Conversion routes** catalogue opens the actual local studio for each available route. Listing a route is not proof that every file variant or native picker has been tested. Each export asks for a destination; save to a new name/location to preserve the source.

| Input → output | Engine / entry point | Fidelity and limits | Validation |
| --- | --- | --- | --- |
| PNG/JPEG/WebP → PNG or JPEG | Bounded image engine; Photo Studio | First frame only; re-encoded output. JPEG quality adjustable; transparency becomes white. Input ≤8 MiB, 12 MP and 8192 px per side; working output ≤16 MiB. Metadata is not guaranteed to survive and size reduction is not guaranteed. | Decoder/header validation and image processor/widget tests; native provider behavior still needs device checks. |
| Images → multipage image PDF | Scan & assemble, image processor and PDF writer | Up to 8 pages, 24 MP and 32 MiB processed images; shared ISO A/B/C, US/ANSI, photo/card/badge/label/poster presets or custom 20–2500 mm page dimensions, 10 mm margins and optional orientation auto-selection. Image-only, not searchable; source metadata is not preserved. | Scan processor/PDF/widget tests and independent PDF inspection; native camera/printing behavior unverified. |
| Earlier .dsproject → .dsdesign | DeskSuite model conversion | Imports a supported older project as a new editable copy. Original remains unchanged. Unsupported, malformed or oversized data is rejected. | Legacy import and workflow integration tests. |
| .dsdesign → PNG or one-page PDF | Creative Studio canvas renderer | Physical page dimensions preserved. PDF/PNG are flattened raster output, not editable/selectable design text. Output is capped at 16 MP and 8192 px per side; large pages require a supported lower DPI. | Export and workflow integration tests; native save/print services need device verification. |
| Photo → imposed photo-sheet PDF | Photo Sheet engine | Separate finished-photo dimensions from physical sheet/media dimensions. Shared media catalogue includes ISO A/B/C, US/ANSI, photo paper, cards/badges, labels, posters and custom sizes. Stock type is a production choice, not proof of printer capability or passport compliance. | Physical page boxes and sheet geometry tested; printer feed path, stock, scaling and borderless behavior need device checks. |
| Image → reviewed text, TXT, DOCX or searchable PDF | Offline Tesseract 5.5.1 via Tesseract4Android; Text extraction | English and Kiswahili models. Word confidence and editable review are provided. Searchable PDF keeps the page image and adds an invisible word-level text layer. Tables, columns and handwriting are not reconstructed. Inputs above the OCR safety bounds are refused. | OCR engine/export/searchable-PDF/image-preparation tests; recognition quality on actual devices remains unverified. |
| Office document → content-level edited DOCX/XLSX/ODT/ODS/PDF/TXT/CSV | Local Office readers/writers and content editor | Readable paragraphs/table cells can be edited and exported as a new copy. Full Word/Excel/PowerPoint layout, images, exact fonts, formulas, charts, macros and complex objects are not preserved. Legacy DOC/XLS/PPT need an external Office engine. | Office engine/converter/content-editor tests; real-world fidelity unverified. |
| Existing PDF → view, annotate/edit supported content, save a separate PDF copy | PDF Studio using pinned dart_pdf_editor 10.0.0 | Supported existing-PDF editing, bounded to 48 MiB input/output. A header check is not full validation; encrypted, malformed, complex or large documents may fail. | Full CI, independent reader checks and physical-device memory/performance tests remain release gates. |
| Multiple PDFs → one combined PDF | PDF Studio `combinePdfsInBackground` with `pdf_document` 10.0.0 | Up to 10 inputs and 48 MiB aggregate source bytes; validates inputs and output page count, preserves source order and exports a new copy. Password-protected/unsupported PDFs may fail. | Engine and UI tests added in the integration branch; CI, independent reader and physical-device memory checks remain gates. |

## Explicitly unavailable or not yet verified

- Password/PIN-encrypted PDF export. The current image/design/scan PDFs are not encrypted. A PIN prompt without real encryption is not security.
- PDF-to-Office conversion, automatic OCR on every PDF, batch structural compression, guaranteed target-byte output and cloud conversion.
- Guaranteed editing of every PDF feature, including every protected, malformed, form-heavy or digitally signed file. Keep an independent original.
- Layout-faithful Office conversion without a verified external Office engine.
- Printer capability discovery, guaranteed stock/finish selection, borderless printing, crop marks, bleed, CMYK profiles and production queues.
- Image segmentation/background removal, face detection or official passport/ID compliance from a generic size preset.

No file is converted by merely renaming an extension. All processing is local by default, but input limits do not guarantee operation on every device.
