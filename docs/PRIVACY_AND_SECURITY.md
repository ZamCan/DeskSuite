# Privacy and security

- Designs, notes and products are stored in the application's private support directory. The app does not require an account, analytics, an API key or a cloud service for editing and local processing.
- Storage is **not encrypted by DeskSuite**. Device backups, exports, a chosen document provider and operating-system print services may retain or transmit copies. A user-selected network printer can use a network. Android debug tooling and plugin manifests may declare permissions; inspect the final merged manifest for any release.
- Import copies bytes and does not intentionally modify the source. Input length, formats, identifiers, nesting, geometry and pixel counts are bounded; native picker implementations may create a cache copy before the Dart limit is checked. Never assume hostile images are harmless, and keep dependencies updated.
- Writes use same-directory temporary files, flushes, serialized operations within a store and recovery for interrupted backup replacement. This is not a transactional database, multi-process lock, filesystem snapshot or power-loss guarantee. Errors are displayed for primary workflows. User-directed exports are separate copies.
- Local data can be lost on uninstall, clear-data, hardware loss or failed migration. **Full suite backup/restore and automatic migration between Android package IDs are not implemented.** Export individual projects, notes and catalogue records and verify copies before changing installations. Catalogue/notes import is not currently a UI feature.
- Never commit signing keys, passwords, access tokens, private project files or `key.properties`. A credential exposed in conversation or logs should be revoked/rotated. Existing `.gitignore` rules are safeguards, not a secret scanner. Review dependency/licence/security notices and native permissions before release.

Business data is a starter catalogue, not an accounting system. For money, legal compliance, sensitive images or irreplaceable work, maintain independent verified backups and do not rely on this build as the sole record.
